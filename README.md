# Susmita Adhikari — Personal Portfolio

A responsive personal portfolio website with an elegant white, beige and sage-green design.

## Publish with GitHub Pages
1. Create or open your repository named `YOUR-GITHUB-USERNAME.github.io`.
2. Upload `index.html` to the top/root level of the repository (not inside another folder).
3. Click **Commit changes**.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
6. Wait a few minutes. Your site address will be `https://YOUR-GITHUB-USERNAME.github.io/`.

- Check the experience dates and wording so they accurately reflect your work history.
- Add a LinkedIn link or profile photo only if you want to.
